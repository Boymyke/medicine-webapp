# MediFind — Medicine Availability Network

A responsive medicine availability and pharmacy network prototype built with Next.js, TypeScript, Inter, and Feather icons.

## Included

- Live-style medicine search and availability results
- Nearby verified pharmacy inventory cards
- Price comparison and stock indicators
- Recent order tracking
- HMO / insurance connection surface
- Pharmacy inventory, hospital API, and integrations entry points
- Responsive desktop/mobile dashboard
- Custom medical favicon

## Stack

- Next.js 15
- React 19
- TypeScript
- `@fontsource/inter`
- `react-feather`

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Product direction

The current UI is a front-end foundation for a larger network consisting of a consumer medicine-search experience, pharmacy SaaS inventory sync, ordering/fulfilment, HMO eligibility, hospital integrations, and partner APIs.
